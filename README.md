# Nova Art Collective

## Overview
Nova Art Collective is a multi-page digital art gallery web application that showcases famous paintings along with their historical background, artist information and it's cultural significance. The project demonstrates the integration of front end web development with structured data handling using XML, DTD, and XSL.

The goal of this project is to create a calm, visually engaging gallery experience where users can explore classic artworks in a curated digital space.

---

## Features
- Multi-page art gallery website with individual artwork pages  
- Curated collection of famous classical paintings  
- Detailed descriptions and historical context for each artwork  
- Sidebar navigation for seamless browsing  
- Responsive card-based gallery layout using CSS Flexbox  
- XML-based structured data storage for artworks  
- DTD validation to ensure data consistency  
- XSL transformation to display XML data in tabular format  

---

## Tech Stack
- HTML5 – Structure and content  
- CSS3 – Styling and layout (Flexbox, hover effects, animations)  
- XML – Structured data representation  
- DTD – Data validation rules  
- XSL – XML transformation and display

## How It Works
1. Artwork data is stored in XML format  
2. DTD validates the structure and ensures consistency  
3. XSL transforms XML into a readable table format  
4. HTML/CSS renders the interactive gallery interface  
5. Users navigate through artworks using sidebar links  

---

## Setup Instructions
1. Clone the repository  
2. Ensure all files (HTML, CSS, XML, images) are in the same directory structure  
3. Open `index.html` in any modern web browser  
4. For XML viewing, open `artworks.xml` via a browser or XML viewer
